# 产品需求基线

## 核心流程

启动纯地球首页 → 点选国家查看图片和介绍 → 选择城市 → 城市简介 → 随机当地人卡片 → 右滑加入聊天列表 → 聊天与交换联系方式 → 双方建立行程记录 → 行程结束后评价。

## 导航及视觉

底部只有地球、聊天、Profile三个图标。首页采用黑色夜幕、自然卫星质感地球和简洁搜索框，不叠加品牌、标题、标语、说明或桌面装饰文字。地球参考苹果地图的自然地貌和大气观感，展示静态日间地表、夜灯、地形和云层；不代表实时天气或当前昼夜。国家和城市的图片、介绍、操作入口在点选后的浅色详情中展开，聊天与Profile继续使用纸色内容界面。社区位于城市故事及个人动态二级入口。保留柔和大气层、珊瑚收藏点、淡绿/淡红滑动光晕。手机竖屏优先，中英双语，语言切换保留在非首页入口。地球影像来源可从设置查看。

## 地图及城市

支持拖动、缩放、国家聚焦、城市选择、国家/城市/景点中英文与别名搜索。城市简介约占可用高度2/3。城市右滑或按钮收藏，在地图留下红点，可取消。返回保留视角、选中城市和浏览进度；收藏跨设备同步。

国家详情包含独立的分段介绍、明亮地标插画和城市列表；未收录国家显示明确空态。当前演示内容覆盖18个国家和65个城市，插画明确区别于实景照片。Profile提供当地人与游客示例主页，均标注演示身份，不影响人物的随机推送规则。

## 随机人物

按城市服务范围、有效账号、审核通过及拉黑关系形成候选。不按价格或特长排序，这些是展示资料。每轮随机快照、分页、无重复、提前加载，耗尽后可开始新一轮。未来可替换为推荐服务。

人物横向拖动时光晕随进度增强；向右淡绿，向左淡红。达到卡片宽度25%后松手完成，不足则回弹。右滑原子创建或复用会话，留在浏览页、显示下一人和新对话提示；左滑仅略过本轮。不用未读数字冒充新对话提示。进入人物主页后可返回同一位置。未登录操作保留意图，登录验证后恢复。

## Profile 与 Agent

基础身份区域包含头像、名称、真实认证。正文为两列可编排组件：介绍、图片集、经历、特长、服务城市、套餐、动态、评价、社媒。支持半宽/整宽、紧凑/展开、添加删除排序、背景/强调色/主题、预览发布及历史恢复。

用户可用自然语言生成或连续调整主页。后端真实模型返回经过校验的结构化布局，由网页和原生组件分别渲染。草稿、生成候选与公开发布分离；基于旧版本的候选不能覆盖新编辑。模型不修改认证、评分或其他事实，不访问私聊、证件或凭据。未配置、超时、无效输出均明确失败并保留现有草稿。

## 聊天及信任

真实账号、邮箱验证、登录与密码重置。聊天包含文字、图片、地点/套餐/联系方式/行程卡片，持久历史、发送状态、重试和已读同步。专业服务者上传证件，非专业提交经历，审核通过后发布套餐。个人套餐含内容、城市、报价及单位，可草稿、发布、编辑、下架。

社区图文、城市关联、评论点赞。举报与拉黑、后台资料审核、内容处理、用户停用、审计。平台不强制付款、不拦截正常联系方式交流，不自动公开私有邮箱。

## 行程和评价

任一方从聊天创建行程记录，对方接受后有效，结束时间修改需重新同意。到约定结束时间、双方确认结束、管理员确认，任一满足开放评价。管理员冻结优先。每人每次行程一条评分及文字。线下记录不标成平台支付订单。

## 交付边界

Android原生、iOS原生、Docker完整网页与后台，共用API和资源。首版不实现线上交易，只预留支付服务边界。未来选择平台付款时提供按规则退款和纠纷处理、履约后结算；站外交易不享受平台订单保障，举报处理仍保留。

## 验收基线

三端功能一致、真实持久化、真实双账号消息、幂等建聊与发送、随机流无重复、Profile真实生成与版本冲突保护、行程三路开放及冻结。并发目标500在线连接与100RPS持续15分钟，实测报告单独记录。
