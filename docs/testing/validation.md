# 验收清单

测试入口和环境要求见 [测试指南](README.md)。每次验收记下提交号、测试环境、实际执行结果和仍待验证的项目。

| 范围 | 检查项 |
| --- | --- |
| Web 地球与底栏 | 冷启动与慢网、完整的底栏静态图、自转和减少动态效果、手动重试、国家锁定与解锁缩回、国家两次点击和城市浏览、搜索分页和重试、手机键盘视口、WebGL 恢复 |
| Web 主页和聊天 | 按数量切换足迹布局、横滑编辑照片、标语和主照片、爱好图片上传与横滑选择、资料和城市编辑、草稿冲突、登录续期、聊天重试 |
| API 与 worker | 鉴权、资源归属、迁移、随机流、消息幂等和补齐、评价资格、邮件与模型队列隔离 |
| 发布 | 页面、样式和图集、`/frontend-version.json`、`/api/v1/ready` |
| Android / iOS | 各自编译和设备验收，检查资源包、自转、登录、人物卡、聊天及主页编辑 |
| 压测与故障恢复 | 在隔离环境运行，记录请求负载、错误率、延迟、资源与恢复时间 |

当前源码的验收以实际运行结果为准。旧安装包、语法报告和历史压测只对应当时的版本，相关记录在 [归档](../archive/README.md)。
