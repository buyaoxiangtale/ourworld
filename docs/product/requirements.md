# 当前产品功能与交付边界

## 核心流程

启动纯地球首页 → 点选国家查看图片和介绍 → 选择城市 → 城市简介 → 随机当地人卡片 → 右滑加入聊天列表 → 聊天与交换联系方式 → 双方建立行程记录 → 行程结束后评价。

## 导航及视觉

底栏有地球、社区、聊天和我的四个入口。星空黑底与黑白灰界面贯穿三端，球形图标使用哑光陶瓷材质、持续自转并区分选中亮态和未选中暗态。「我的」用一道浅刻笑弧表示。首页有胶囊搜索栏和可旋转、缩放的卫星影像地球。大地球显示静态日间影像、地形和大气光晕，云层已合成在影像中。社区作为一级入口展示旅行故事，城市和个人主页仍可访问关联动态。手机竖屏优先，中英双语，影像来源可从设置查看。

## 地图及城市

支持拖动、缩放、国家聚焦、城市选择、国家/城市/景点中英文与别名搜索。城市简介约占可用高度2/3。城市右滑或按钮收藏，在地图留下标记，可取消。返回保留视角、选中城市和浏览进度；收藏跨设备同步。

Web 上首次点选国家聚焦，第二次点选打开分段介绍和地标插画，并可进入城市卡片浏览。原生国家详情使用城市列表。地图仍可点选未收录国家，详情会给出空态。地点数量以 API 当前目录为准，演示人物与资料带示例身份说明。

## 随机人物

按城市服务范围、有效账号、审核通过及拉黑关系形成候选。不按价格或特长排序，这些是展示资料。每轮随机快照、分页、无重复、提前加载，耗尽后可开始新一轮。未来可替换为推荐服务。

人物横向拖动时会显示对应方向的反馈。松手时按距离或甩动速度判断，未达到阈值则回弹。右滑原子创建或复用会话，留在浏览页、显示下一人和新对话提示；左滑仅略过本轮。不用未读数字冒充新对话提示。进入人物主页后可返回同一位置。未登录操作保留意图，登录验证后恢复。

## Profile 与 Agent

基础身份区域包含头像、名称和认证。已发布的布局可以包含介绍、图片集、经历、特长、服务城市、套餐、动态、评价和社交链接。网页端提供简介、照片故事、爱好、语言和资料等独立编辑入口。原生端提供资料、照片、旅行问答和服务城市编辑。

布局 Agent 保留在后端 API 与 worker，当前三个客户端使用逐项编辑入口。调用方可通过 API 请求生成候选布局。草稿、候选与发布各自独立，旧版候选不能覆盖新的编辑。

## 聊天及信任

真实账号、邮箱验证、登录与密码重置。聊天包含文字、图片、地点/套餐/联系方式/行程卡片，持久历史、发送状态、重试和已读同步。专业服务者上传证件，非专业提交经历，审核通过后发布套餐。个人套餐含内容、城市、报价及单位，可草稿、发布、编辑、下架。

社区图文、城市关联、评论点赞。举报与拉黑、后台资料审核、内容处理、用户停用、审计。平台不强制付款、不拦截正常联系方式交流，不自动公开私有邮箱。

## 行程和评价

任一方从聊天创建行程记录，对方接受后有效，结束时间修改需重新同意。到约定结束时间、双方确认结束、管理员确认，任一满足开放评价。管理员冻结优先。每人每次行程一条评分及文字。线下记录不标成平台支付订单。

## 交付边界

Android原生、iOS原生、Docker完整网页与后台，共用API和资源。首版不实现线上交易，只预留支付服务边界。未来选择平台付款时提供按规则退款和纠纷处理、履约后结算；站外交易不享受平台订单保障，举报处理仍保留。

## 验收基线

回归重点包括跨设备持久化、双账号消息、幂等建聊与发送、随机流无重复、主页版本冲突保护、行程评价资格与冻结。浏览器、Android 和 iOS 各自验收，测试入口见 [测试指南](../testing/README.md)。
