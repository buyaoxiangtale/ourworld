# 成熟克制：三端视觉改版

> 历史记录。2026-11-03 最新交付、Android 安装包与验证结果见 [深海改版记录](deep-sea-ui.md)。

网页 React、Android Compose、iOS SwiftUI 共用暖白、炭黑、自然摄影的视觉规范。人物卡片是主要视觉；照片下部集中显示姓名与身份，底部保留「略过」「加入对话」。原生两端继续使用原生组件，地球共用深蓝地图资源，无云层、无昼夜分界。

## 当前增量：深色地图与大幅人物卡（2026-11-03）

地球参考用户提供的手机版 Apple 地图夜间视频，采用黑色背景、深蓝海洋、克制的陆地明暗。没有按“同色”解释为提亮。地表材质不依赖太阳方向、时间或宿主主题；云层、夜间灯光和高程贴图不再加载。轻微球面边缘明暗跟随观察方向，不形成昼夜分界。仅使用既有 NASA 地表影像和本地 world-atlas 轮廓，没有使用 Apple 地图瓦片。

React、Compose、SwiftUI 的人物照片均铺满整张卡片。去掉重复的城市标签、介绍、兴趣和价格白色区块；照片下部只显示姓名及必要身份标识，右下角信息按钮打开完整主页。顶部保留城市与范围筛选，底部为略过和加入对话两个圆形按钮。照片居中裁切，姓名最多两行；AI 演示身份保留。网页三个手机尺寸下照片约占人物浏览区的 79%–86%，占卡片高度 100%。业务接口与用户照片没有改写。

## 规范与素材

- 规范源：`packages/contracts/assets/visual.json`。`node scripts/generate/sync-design.mjs` 生成三端参数，`--check` 检查同步。
- 暖白 `#F5F4F2`、炭黑 `#242322`、辅助灰 `#6D6A67`；少量暖红 `#A14F58` 用于强调和状态。常规卡片圆角 24；人物发现卡片圆角 16、左右边距 10，底部两个操作为 56 的圆形按钮，触摸区域至少 44。
- 8 张成年虚构人物摄影图保存在 `apps/api/assets/photos/portraits`。使用内置 `image_gen`，完整提示词见该目录 `sources.json`。同一演示账号始终映射到同一张照片，卡片、主页和聊天一致；并发演示账号复用这组照片并保留 AI 演示标识。
- 65 座城市的实景照片保存在 `apps/api/assets/photos/places`，18 个国家引用所在地区的代表城市照片。`places.json` 保存作者、原作和许可；三端设置均链接 `/api/v1/photo-credits`。采集脚本为 `scripts/assets/collect-place-photos.py`。

## 数据与兼容

沿用 `avatar`、`image`、相册引用和原有业务接口；增加同源 JPEG 素材接口及摄影来源页。新 API 可直接把已知旧演示素材映射为照片，不要求先写数据库。重新运行种子时也能升级受控演示引用；用户上传、外部地址、带自定义参数的链接和已编辑的文字不被覆盖。图库只转换已知演示图片引用，不改变组件顺序、布局版本或用户主题选择。

原有 SVG、PNG 接口保留兼容。随机快照、25% 滑动阈值、建聊幂等、草稿和发布流程保持。管理后台不应用新的用户端样式。

## 视觉复核

使用 `design-taste-frontend` 的 Achromatic ledger 方向，seed `1598187946`，按用户选定 B 保留暖白/炭黑与现有字体。人物照片是产品的主要识别元素，滑动照片卡是核心操作。24 圆角配合用户要求的手机人物卡片语境。
