# Ourworld shared globe

`npm run build -w @ourworld/globe` produces `dist/index.html`, `dist/mini.html` and self-contained static resources. All geographic data and scripts are bundled, with no runtime CDN. The root build copies this directory to `/globe/` and native app resources.

Bridge v1: receive commands through `window.OurworldGlobe.receive(command)` or a same-origin parent `postMessage`. Events are posted to the parent, `AndroidBridge.postMessage(JSON.stringify(event))`, and `webkit.messageHandlers.ourworldGlobe.postMessage(event)` when available.

Commands: `setMarkers {places:Place[],favoriteIds:string[]}`, `focusPlace {place:Place}`, `restoreCamera {lat,lng,altitude}`, `setActive {active:boolean}`, `setTheme {theme:string}`. Events: `rendererReady`, `placeSelected {place}` (or `geoName,geoId,lat,lng` for countries without a corresponding catalog entry), `cameraChanged {lat,lng,altitude}`, `rendererError {message}`. Every envelope contains `bridgeVersion:1,event,data`.

Tapping a country first highlights it and focuses the camera; tapping that same country again emits `placeSelected` to open its information. Choosing another country starts a new focus. Dragging, zooming, or choosing a city clears this pending country selection. City markers still open on the first tap. Host-initiated `focusPlace` does not echo `placeSelected`, and a country focused through that command can open on its next tap.

`window.OurworldGlobe.ready` is true only after textures load and the WebGL context is usable. Context restoration repaints paused scenes and emits `rendererReady` with `recovered:true`; a context still lost after five seconds emits a recoverable `rendererError`. The web host retries once, restores markers and the last camera, and offers manual reload if recovery fails. Resizing and returning to a visible page repaint without requiring a drag or restarting rotation on an inactive globe.

Geographic outlines are bundled from world-atlas/Natural Earth 1:110m. 1:50m stays available in `world-atlas` if per-country coastline detail is ever required, but 110m keeps the polygon layer and bundle light with no visible difference at globe scale. `src/atlas.ts` applies the reviewed territory merges before any consumer reads the data (currently Taiwan into China, by ISO id with a name fallback); `feature()`, `geoContains()`, the land mask and the selection style all inherit the merged shape. Merged entries must not share arcs with their target. Re-run `uv run ourworld test web globe-boundaries` after any `world-atlas` upgrade. Basemap data is display data, not an administrative-boundary certification. Maintain reviewed local source data for a production geography release. The main renderer loads `earth-day.jpg` and the `earth-topology.png` relief map locally. No imagery is requested from a remote host.

The four navigation planets share the matte ceramic rendering in `src/planet-icons.ts`. The Web app bundles their first frames and starts loading the live miniature Earth and rotation atlases after the main globe entrance finishes. The native miniature view renders the Earth live with the local atlas as its fallback. After changing the renderer, run `uv run ourworld browsers`, then `PLAYWRIGHT_BROWSERS_PATH="$PWD/.playwright-browsers" node scripts/generate/render-planet-icons.mjs` from the repository root and rebuild the shared assets. The generator writes the atlases to `public/textures` and the Web stills to `apps/web/src/assets/planet-icons`.
