# Ourworld shared globe

`npm run build -w @ourworld/globe` produces `dist/index.html`, `dist/mini.html` and self-contained static resources. All geographic data and scripts are bundled, with no runtime CDN. The root build copies this directory to `/globe/` and native app resources.

Bridge v1: receive commands through `window.OurworldGlobe.receive(command)` or a same-origin parent `postMessage`. Events are posted to the parent, `AndroidBridge.postMessage(JSON.stringify(event))`, and `webkit.messageHandlers.ourworldGlobe.postMessage(event)` when available.

Commands: `setMarkers {places:Place[],favoriteIds:string[]}`, `focusPlace {place:Place,locateOnly?:boolean}`, `restoreCamera {lat,lng,altitude}`, `setActive {active:boolean}`, `setTheme {theme:string}`. Events: `rendererReady`, `placeSelected {place}` (or `geoName,geoId,lat,lng` for countries without a corresponding catalog entry), `cameraChanged {lat,lng,altitude}`, `rendererError {message}`. Every envelope contains `bridgeVersion:1,event,data`.

The Web host opts into street maps with `setMarkers {streetMap:true}`. A user zooming in to close range emits `streetMapRequested {lat,lng}`. The host opens a street map centered at that point. City details can also open it at a closer zoom. Street maps use MapLibre and OpenFreeMap vector tiles, with a Leaflet and OpenStreetMap raster fallback if tiles fail to load or WebGL is unavailable. Both load tiles on demand and display attribution. The globe itself loads its map data and imagery locally.

The first map tap on a country highlights it and focuses the camera. Cities from the locked country's catalogue appear at their coordinates. A city label opens its details, while a second tap on the country opens country details. A locked globe can be dragged manually. Tapping the ocean or sky clears the selection and resumes autorotation at the current zoom, subject to the reduced-motion preference. The Web search flow resolves city and landmark results to their country and sends `focusPlace` with `locateOnly: true`, which also shows a pin for the country.

`window.OurworldGlobe.ready` is true only after textures load and the WebGL context is usable. Context restoration repaints paused scenes and emits `rendererReady` with `recovered:true`; a context still lost after five seconds emits a recoverable `rendererError`. The web host retries once, restores markers and the last camera, and offers manual reload if recovery fails. Resizing and returning to a visible page repaint without requiring a drag or restarting rotation on an inactive globe.

Geographic outlines use bundled world-atlas/Natural Earth 1:110m data for the overview. When the projected globe is about 1.27 times its overview size, the renderer loads the 1:50m coastlines and borders from a separate local chunk. The same detail data drives country hit testing at close zoom. Both scales apply the territory merge in `src/atlas.ts` (currently Taiwan into China, by ISO id with a name fallback). Merged entries must have disjoint arcs. Re-run `uv run ourworld test web globe-boundaries` after a `world-atlas` upgrade. The main renderer loads `earth-day.jpg` and the `earth-topology.png` relief map locally.

The four navigation planets share the matte ceramic rendering in `src/planet-icons.ts`. The Web app bundles their first frames and starts loading the live miniature Earth and rotation atlases after the main globe entrance finishes. The native miniature view renders the Earth live with the local atlas as its fallback. After changing the renderer, run `uv run ourworld browsers`, then `PLAYWRIGHT_BROWSERS_PATH="$PWD/.playwright-browsers" node scripts/generate/render-planet-icons.mjs` from the repository root and rebuild the shared assets. The generator writes the atlases to `public/textures` and the Web stills to `apps/web/src/assets/planet-icons`.
